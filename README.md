(для корректной работы карты и View Transitions лучше через локальный сервер:
`python -m http.server 8000` в этой папке → http://localhost:8000).

```

  css/tokens.css      — дизайн-токены (= переменные Figma, Code syntax в Dev Mode)

  css/pages.css       — композиции блоков конкретных страниц
  js/main.js          — поведение: меню, табы, карусели, маска телефона, формы, анимации
  img/*.webp          — изображения из макетов (WebP)

images/               — ОРИГИНАЛЫ всех картинок из макета Figma в исходном качестве (jpg/png, 58 файлов).
                        Для передачи дизайнеру/на сайт. Вёрстка их не использует — она берёт

  content-plan.md     — семантика, порядок блоков, SEO / GEO / AEO, CRO-правки

```

## Правила, заложенные в вёрстку

**Тексты будут меняться**
- Нет фиксированных высот у блоков с текстом — только `min-height`.
- Заголовки и описания карточек обрезаются `line-clamp: 3`, сетки не ломаются.
- Все размеры шрифтов — из токенов; увеличение шрифта браузера до 200% не ломает раскладку.
- Сетки `grid` с `minmax(0, 1fr)`: карточек может стать больше или меньше — перестроятся сами.
- Длинные слова переносятся (`overflow-wrap`), flex-элементы с `min-width: 0`.

**Адаптив**: 1200+ (контейнер 1380) · 768–1199 (планшет) · до 767 (мобильный, значения режима Mobile из Figma).
На мобильном токены переопределяются в `tokens.css` — компоненты не трогаем.

**Анимации** (все отключаются при `prefers-reduced-motion`)
- Появление секций при скролле, каскад карточек (`.reveal`, `data-stagger`).
- Hover: подъём карточек + тень, zoom фото, блик на главной кнопке, стрелки, подчёркивание меню.
- Счётчики цифр, «растущие» полосы зарплат, плавающие 3D-иллюстрации, пульс кнопки видео.
- Переходы между страницами: View Transitions (Chrome/Edge) + мягкое затухание в остальных браузерах.

**Доступность**: skip-link, `:focus-visible`, aria у табов/меню/модалок, закрытие по Esc, alt у изображений.

## Что подключает бэкенд (помечено `TODO backend` в main.js)

- Отправка форм `form[data-lead]` → CRM + цель Метрики. Сейчас: валидация и модалка «Спасибо».

## SEO-разметка (уже в страницах)

Один `<h1>` на страницу, `<title>`/`description` под ключевые запросы, `canonical`, Open Graph,
JSON-LD: EducationalOrganization, BreadcrumbList, FAQPage, Course + CourseInstance, Event, Person.
Корзина и оформление закрыты `noindex`.

## Требует данных от заказчика

Помечено в текстах `[уточнить]`/`[проверить]`: ИНН/ОГРН, условия рассрочки, Telegram,
цифры «350 000+», «95%», зарплаты, реальные отзывы и логотипы партнёров, единый номер телефона
(в исходных макетах было два разных: 430-03-74 и 430-03-65).

Шрифт: Onest (Google Fonts). Если есть лицензия TWK Everett — заменить `--font-base` в `tokens.css`
и подключить `@font-face`.

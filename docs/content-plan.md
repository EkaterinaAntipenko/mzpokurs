## Принципы текста
- Первая фраза каждого блока — прямой ответ (AEO/GEO: нейросети цитируют первые 1–2 предложения).
- Конкретика вместо общих слов: часы, документ, реестр, формат, цена, срок.
- CTA = глагол + выгода: «Подобрать курс», «Записаться на курс», «Получить консультацию».
- Только проверяемые факты. Цифры, которые нужно подтвердить у заказчика, помечены [проверить].

## Остальные страницы
- Расписание: H1 «Расписание курсов и ближайшие даты старта групп»; фильтр → список курсов → таблицы дат.
- Мероприятия: H1 «Мероприятия и дни открытых дверей»; featured-карточка первой.
- Преподаватели: H1 «Преподаватели МЦПО — практикующие врачи и эксперты»; группы по факультетам.
- Контакты: H1 «Контакты учебного центра МЦПО в Москве»; карта + реквизиты + форма.
- Корзина / Оформление: без изменения порядка, микротексты про вычет 13% и ФИС ФРДО.

## Правки для конверсии (CRO)
Быстрые:
1. Одна главная кнопка на экран; «Записаться» → «Записаться на курс», «Отправить» → «Подобрать курс».
2. Телефон одинаковый везде: в макетах 430-03-74 (шапка) и 430-03-65 (подвал) — выбрать один [проверить].
3. Форма: 2 обязательных поля (имя, телефон), email — необязательный.
4. Под формой — «Перезвоним за 15 минут в рабочее время» (снижает тревогу).
5. Цены: «от 19 100 ₽» + «можно в рассрочку / вычет 13%» рядом с ценой.
Крупные:
6. Отдельная посадочная «Аккредитация медработников» и «Курсы НМО для врачей» — основной спрос врачей.
7. Квиз подбора курса (4 вопроса) — мягкая конверсия.
8. Sticky-кнопка «Записаться» на мобильной странице курса.
Гипотезы A/B: заголовок hero (выгода vs категория), CTA «Подобрать курс» vs «Получить консультацию», форма в hero курса vs кнопка.

## SEO (Яндекс + Google)
- ЧПУ-подпапки: /kursy/massazh/klassicheskij-massazh/ ; 301 со старых URL (distatsionnye-kursy/… , course/massazhp/…).
- Один H1, H2 = заголовки секций; title ≤ 60, description ≤ 160 с часами/документом/ценой.
- Микроразметка: EducationalOrganization, Course (+CourseInstance с датами), FAQPage, BreadcrumbList, Event, Person, Review (только реальные).
- Коммерческие факторы Яндекса: цены, телефон, адрес, реквизиты, лицензия со ссылкой на реестр Рособрнадзора, способы оплаты, «Сведения об образовательной организации».
- Скорость: WebP/AVIF, lazy-load, карта по клику, шрифт с font-display: swap.
- Перелинковка хаб → курсы → связанные курсы.

## GEO / AEO (нейросети: Алиса, YandexGPT, Google AI Overviews, ChatGPT)
- Блоки «вопрос → прямой ответ» (FAQ) на каждой коммерческой странице.
- Факты в тексте, не в картинках: «лицензия № Л035-01298-77/00350290», «с 1998 года», «удостоверение в ФИС ФРДО».
- Единое название сущности: «АНО ДПО „Международный центр профессионального образования“ (МЦПО)» — в подвале, «О центре», разметке, Яндекс Бизнесе, 2ГИС.
- Преподаватели с ФИО, специальностью и стажем → E-E-A-T.
- Страница-глоссарий: «Что такое НМО», «Как пройти периодическую аккредитацию» — информационный спрос, который цитируют ИИ.
